# El Niño Ready

Source for **https://elninoready.earth** — a static site, no build step.

- `index.html` is the whole site. `thanks.html` and `thanks-idea.html` are the form landing pages.
- Push to `main` and Netlify deploys it automatically within about a minute.
- Forms (`get-involved`, `ideas`) are Netlify Forms; submissions show up in the Netlify dashboard.
- `VISION.md` is the mission doc the copy is drawn from.

Style: emergency-bulletin. IBM Plex Mono, black on white, hard borders, no gradients. Keep it that way.
